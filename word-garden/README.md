# Word Garden · 單字小花園

家庭自用的英文學習試用版。新增於獨立 `word-garden/` 目錄，不修改原有 Jekyll 首頁或網站設定。

## 使用

以 Safari 或現代瀏覽器開啟 GitHub Pages 的 `word-garden/` 路徑。右上角可選小狐狸、小兔子或大人練習；每位學習者的進度分開記錄。家長工具可修改暱稱、切換聽讀／拼字、調整語音、新增單字及匯出／匯入 JSON 備份。

## 內容與行為

- 30 個自編示範單字、5 個生活主題、英文例句及繁體中文說明。
- 教學卡、聽音選意思、閱讀辨認、點選字母拼字、短句填空。
- 首次作答與提示分開；錯題最多在同一輪重試一次。
- 聽、讀、拼字、短句分開記錄；同日重複答對不加速複習間隔。
- 每日任務完成只累積一天，不扣分、不因中斷歸零。
- 原生 HTML/CSS/JavaScript，無建置相依、無第三方追蹤。

## 資料與限制

使用 localStorage 保存這台裝置的資料，沒有跨裝置同步或帳號系統。清除瀏覽器資料可能失去進度，請定期匯出。匯入會取代本機資料，需確認。

不將學習者暱稱、自訂教材或作答紀錄上傳至本網站伺服器。語音使用瀏覽器 SpeechSynthesis，裝置提供的語音服務可能需要網路；不錄音、不提供發音評分。家長頁面沒有密碼保護。Emoji 是輔助符號，不是正式圖解教材；沒有宣稱官方 CEFR 分級。

Service worker 僅限本子目錄，嘗試快取介面。朗讀不保證離線可用；不同 iPad 聲音與顯示仍需實機確認。

## 驗證

本機 Chromium 以自編 HTML 執行 45 個檢查，涵蓋不同尺寸版面、聽讀／拼字、提示與重試、學習者切換、新增單字、備份匯入和輸入跳脫。因測試環境限制，頁面透過 set_content 載入並用記憶體 storage adapter 驗證序列化與復原；不是實體 iPad、實際音訊或瀏覽器持久儲存的完整驗收。
